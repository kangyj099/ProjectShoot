## 1. 개요

### 1.1 목적
데미지 시스템은 "무엇이 무엇에게 얼마만큼의 HP를 깎는가"를 정의한다. 본 게임은 캐주얼 아케이드 장르이므로 방어력·크리티컬·랜덤 변동 같은 RPG식 변수를 두지 않고, **"맞으면 정해진 만큼 깎인다"**는 직관적인 구조를 지향한다.

본 문서는 새 데미지 값을 정의하지 않는다. 데미지 값 자체는 이미 다른 문서에 정의된 필드(총알스킬시스템 2.4의 "데미지" 오버라이드 필드, 몬스터 데이터의 "충돌 데미지")에 있으며, 본 문서는 **그 값들이 실제로 언제·누구에게·어떤 조건으로 적용되는지**, 그리고 **공격력 증가 강화와 일시 공격 배수 아이템이 그 값을 어떻게 키우는지**를 공식으로 완성하는 역할이다. 아이템 자체(분류·획득·레벨·배출·튕김·점수 전환)의 원본은 아이템시스템 v1.3이다.

### 1.2 플레이어 경험 목표
- **예측 가능한 피해**: 같은 탄에 맞으면 항상 같은 만큼 깎인다 — 플레이어가 "이건 몇 대 더 버틸 수 있다"를 감으로 학습 가능
- **억울한 순삭 방지**: 피격 후 고정 무적시간으로, 탄막이 겹쳐 한 순간에 HP가 통째로 날아가는 상황을 방지
- **위협의 위계**: 몹 종류마다 탄막/충돌 데미지가 달라, "강한 적의 공격일수록 더 피해야 한다"는 우선순위가 자연스럽게 생김

## 2. 상세 규칙

### 2.1 데미지 방향과 출처 (전체 구조)

| 방향 | 데미지 출처 | 값의 정의 위치 |
|---|---|---|
| ① 플레이어 → 적 | 플레이어 스킬(무기) 탄 | 총알스킬시스템 2.4 "데미지" 오버라이드 필드 (플레이어용) |
| ② 얼라 → 적 | 얼라 스킬 탄 | 총알스킬시스템 2.4 "데미지" 오버라이드 필드 (얼라용) |
| ③ 적 → 플레이어 (탄막) | 몬스터 스킬 탄 | 총알스킬시스템 2.4 "데미지" 오버라이드 필드 (몬스터용) |
| ④ 적 → 플레이어 (충돌) | 몬스터 몸체 접촉 | **몬스터 데이터의 "충돌 데미지" 필드** (몹 종류별 개별 값) |
| ⑤ 적 → 얼라 | 몬스터 탄막/충돌 | ③·④와 동일 값 사용 (얼라도 HP 보유 — 갈고리시스템 2.3) |

> **핵심 원칙**: 탄막 데미지는 "그 탄을 쏜 스킬"의 데미지를, 충돌 데미지는 "부딪힌 몹"의 데미지를 따른다. 같은 몹이라도 탄에 맞을 때와 몸통에 부딪힐 때 피해량이 다를 수 있다.

> 변수명을 `PlayerAtk` / `AllyAtk` / `EnemyAtk`로 나눈 이유: 세 값 모두 같은 "데미지" 필드에서 나오지만 사용 주체별 오버라이드 값이 다르므로, 밸런스팀이 표를 볼 때 혼동하지 않도록 이름부터 구분한다. 이 세 값은 아래 무기 데미지 공식의 `BaseAtk` 자리에 들어간다.

### 2.2-1 무기 데미지 공식 — 아이템 반영 *(v1.4 개정)*

$$WeaponDmg = \left\lfloor BaseAtk \times \left(1 + EnhAtk\right) \times AtkMult \right\rfloor$$

- `⌊ ⌋` = 버림. **곱셈을 모두 끝낸 뒤 마지막에 한 번만 버린다** (v1.3 확정)
- v1.3까지의 `min(ΣItem, ItemCap)` 자리에 `EnhAtk`가 들어간다. 공격력 증가 강화는 슬롯 1칸·최대 Lv3이므로 **합산할 대상이 없고, 상한은 Lv3 값 자체**가 된다

| 항목 | 규칙 |
|---|---|
| `BaseAtk` | **현재 주체가 사용 중인 무기(스킬)의 공격력.** 주체에 따라 `PlayerAtk(skill)` / `AllyAtk(skill)` / `EnemyAtk(skill)` 중 하나. 기체·캐릭터 고유 공격력은 두지 않음 |
| 아이템 효과 적용 주체 | **플레이어만** (v1.3 확정). 얼라·적은 항상 `EnhAtk = 0`, `AtkMult = 1` → `WeaponDmg = BaseAtk` |
| 적용 대상 | 무기(스킬) 탄에 의한 데미지만. **몸체 충돌 데미지(`ContactDmg`)는 이 공식을 거치지 않음** |
| 공격력 증가와 배수의 관계 | `(1 + EnhAtk)`에 `AtkMult`를 **곱한다** |
| 다른 강화 종류 **(v1.4)** | 탄 개수 증가·탄 크기 증가는 **탄 1발 데미지를 바꾸지 않음** (발사 형태만 변경 — 총알스킬 v1.3 2.6). 포션·최대 HP 아이템은 데미지와 무관 |
| 무기 교체 시 | 강화 슬롯과 현재 배수 효과(남은 시간 포함)는 **그대로 유지**, 새 무기의 `BaseAtk`에 바로 적용 (v1.3 확정) |

**공격력 증가 강화 규칙** *(v1.4 개정 — 원본: 아이템시스템 v1.3 2.6)*

| 상황 | `EnhAtk` 변화 |
|---|---|
| 공격력 증가 강화 미보유 | 0 |
| 처음 획득 (Lv1) | `EnhValue(AtkUp, 1)` |
| 같은 종류를 또 획득 (레벨업) | `EnhValue(AtkUp, lv+1)` — 레벨별 값은 직접 지정 |
| Lv3에서 같은 종류와 접촉 | 변화 없음. 아이템은 **흡수되고 점수로 전환** (v1.5 변경) |
| 슬롯이 가득 찬 상태에서 새 종류 강화를 먹어 **공격력 증가가 배출됨** | **즉시 0**. 다음 탄부터 적용 |
| 배출됐던 공격력 증가 아이템을 다시 주움 | 그 아이템의 레벨 값으로 복구 (아이템시스템 v1.3 5장 N 결정에 따름) |
| 스테이지 전환 | 유지 (코어루프 2.4) |
| 게임오버 | 0으로 초기화 |

**일시 공격 배수 아이템(약칭: 배수 아이템) 규칙**

배수 효과는 한 번에 하나만 적용된다. 새 배수 아이템과 접촉했을 때의 처리:

| 상황 | 처리 | 예시 |
|---|---|---|
| 같은 배수를 다시 먹음 | **새로 먹은 아이템의 지속시간으로 갱신(최신화)** (v1.3 확정) | 1.5배 남은 5초 중 1.5배 20초 획득 → 1.5배 20초 / 1.5배 남은 25초 중 1.5배 10초 획득 → 1.5배 10초 |
| 약한 배수 중 강한 배수를 먹음 | **강한 배수로 교체. 약한 배수의 남은 시간은 소멸** | 1.5배 남은 18초 중 2배 10초 획득 → 2배 10초, 끝나면 배수 없음 |
| 강한 배수 중 약한 배수 획득 **(v1.5 변경)** | **흡수되고 효과 대신 점수(`OverflowBonus`) 지급** (아이템 v1.3 2.7-2, 스코어 v1.4). 현재 배수·시간 그대로 | 2배 남은 6초 중 1.5배 획득 → 2배 남은 6초 그대로 + 점수 |
| 지속시간 종료 | `AtkMult = 1` | — |

> 참고: "같은 배수를 다시 먹으면 최신화" 규칙 때문에, 남은 시간이 더 긴 상태에서 짧은 아이템을 먹으면 시간이 줄어든다. 의도된 동작이며, UI에서 갱신된 시간을 즉시 보여줘야 플레이어가 혼란스럽지 않다.

**계산 예시 (구조 이해용 — 수치는 예시일 뿐 확정값 아님)**

권총 `PlayerAtk = 20`, 공격력 증가 `EnhValue` = Lv1 0.10 / Lv2 0.25 / Lv3 0.45 가정:

$$WeaponDmg = \lfloor 20 \times (1 + 0.25) \times 2 \rfloor = 50 \quad \text{(Lv2 + 2배)}$$

| 상태 | `EnhAtk` | 배수 | 탄 1발 데미지 (버림 후) |
|---|---|---|---|
| 아이템 없음 | 0 | 1 | 20 |
| 공격력 Lv1 | 0.10 | 1 | 22 |
| 공격력 Lv1 + 1.5배 | 0.10 | 1.5 | ⌊33.0⌋ = 33 |
| 공격력 Lv2 + 2배 | 0.25 | 2 | 50 |
| 공격력 Lv3 + 2배 (최대) | 0.45 | 2 | 58 |
| 공격력 증가가 배출된 직후 + 2배 | 0 | 2 | 40 |

### 2.3 공식 ① — 적이 받는 데미지 (가해 공식)

$$EnemyHP_{현재} \leftarrow EnemyHP_{현재} - WeaponDmg_{플레이어} \quad \text{(플레이어 탄 적중 시, } BaseAtk = PlayerAtk(skill))$$

$$EnemyHP_{현재} \leftarrow EnemyHP_{현재} - WeaponDmg_{얼라} \quad \text{(얼라 탄 적중 시, } BaseAtk = AllyAtk(skill))$$

- `WeaponDmg`는 2.2-1 공식으로 계산. 얼라는 아이템 효과를 받지 않으므로 `WeaponDmg_얼라 = AllyAtk(skill)`
- 방어력·크리티컬·랜덤 변동 **없음** — 같은 상태에서는 탄 1발 = 고정값 1회 차감
- 적에게는 무적시간 없음 — 탄이 맞는 족족 데미지 적용 (연사형 무기·탄 개수 증가의 체감 화력을 보장)
- **몸체 충돌로는 적이 데미지를 받지 않음 (v1.1 확정)**
- `EnemyHP ≤ 0` → 처치 판정 → 스코어시스템 `Score_kill` 발생, **아이템 드랍 판정 발생 (아이템시스템 v1.3 2.3)**

### 2.4 공식 ② — 플레이어가 받는 데미지 (피격 공식)

**피격 처리 순서**

| 순서 | 처리 |
|---|---|
| 1 | 플레이어가 적 탄 또는 적 몸체와 접촉 |
| 2 | 현재 무적시간 중인지 확인 → 무적 중이면 **데미지 무시, 종료** |
| 3 | 데미지 결정: 탄이면 `WeaponDmg_적`(`BaseAtk = EnemyAtk(skill)`), 몸체면 `ContactDmg(enemy)`. **같은 프레임에 여러 개가 동시에 닿았다면 그중 가장 큰 값 1개만 선택 (v1.1 확정)** |
| 4 | `PlayerHP ← PlayerHP − 데미지` |
| 5 | 무적시간 시작: `IFrameTime`초 동안 추가 피격 무시 |
| 6 | `PlayerHP ≤ 0` → 즉시 게임오버 (코어루프 2.3, 컨티뉴 없음) |

$$PlayerHP \leftarrow PlayerHP - \begin{cases} WeaponDmg_{적} & \text{탄막 피격} \\ ContactDmg(enemy) & \text{몸체 충돌} \end{cases} \quad (\text{무적 중이 아닐 때만})$$

- 적은 아이템 효과를 받지 않으므로 `WeaponDmg_적 = EnemyAtk(skill)`
- **아이템과의 접촉(획득·튕김·점수 전환)은 피격이 아니다** — 데미지·무적시간 모두 발생하지 않음 (아이템시스템 v1.3 2.7)

**무적시간 규칙**

| 항목 | 규칙 |
|---|---|
| 길이 | `IFrameTime` 고정값 (피격 종류·몹 종류와 무관하게 항상 동일) |
| 무적 중 탄 접촉 | 데미지 없음. **탄은 소멸하지 않고 그대로 통과 (v1.1 확정)** |
| 무적 중 사격 | 정상적으로 계속됨 (자동 사격) |
| 무적 중 이동 | 정상적으로 가능 |
| 무적 중 아이템 | 정상적으로 획득 가능 (아이템시스템 v1.3 2.5) |

### 2.5 공식 ③ — 얼라가 받는 데미지

$$AllyHP \leftarrow AllyHP - \begin{cases} WeaponDmg_{적} & \text{탄막 피격} \\ ContactDmg(enemy) & \text{몸체 충돌} \end{cases}$$

- `AllyHP ≤ 0` → 얼라 소멸(빈사), 스코어 감점 없음 (갈고리시스템 2.3)
- **얼라도 피격 후 `AllyIFrameTime` 동안 무적 (v1.1 잠정 확정)**. 처리 순서는 플레이어 피격(2.4)과 동일
- **재검토 조건**: 플레이테스트에서 얼라가 지나치게 오래 살아남는 것으로 확인되면 얼라 무적시간을 제거한다

### 2.6 특수 상황 처리

| 상황 | 처리 |
|---|---|
| 같은 프레임에 탄 여러 발 동시 피격 | **가장 큰 데미지 1회만 적용 (v1.1 확정)** |
| 갈고리 시간정지 중 (갈고리 2.5) | 적 탄막이 멈춰 있으므로 새로 피격될 일이 사실상 없음. 이미 겹쳐 있는 탄과의 접촉은 2.4 규칙 그대로 적용 |
| 갈고리 조준 중 + 시간정지 해제 후 | 조준 상태 자체는 무적을 주지 않음 — 2.4 피격 공식 그대로. 피격 직후 일반 무적시간 발생, 데미지 경감 없음 (v1.1 확정) |
| HP 회복·최대 HP **(v1.5 개정)** | ① **포션**: 단축키로 사용, `PlayerHP += PotionHeal`, `PlayerMaxHP`를 넘지 않음 (아이템 v1.3 2.6 ②) ② **최대 HP 아이템**: `PlayerMaxHP` +`MaxHPItemUp`(20), 같은 양만큼 `PlayerHP`도 증가, 상한 `MaxHPCap`. **보스 처치 시 확정 드랍·자동 흡수** (아이템 v1.4 2.3 ⑤) ③ 스테이지 클리어 회복 `ClearHeal`은 밸런스 생존기준축 v1.2. 보스 처치 시 처리 순서: 최대 HP 아이템 → 클리어 회복. ④ 포션은 HP가 가득 차면 사용 불가. **포션 사용·최대 HP 증가는 피격이 아니므로 무적시간이 발생하지 않음** [제안] |

### 2.7 계산 예시 (구조 이해용 — 수치는 예시일 뿐 확정값 아님)

`PlayerMaxHP = 100`, `IFrameTime = 1.0초`, 잡몹 탄 `EnemyAtk = 10`, 잡몹 `ContactDmg = 20`, 보스 탄 `EnemyAtk = 25` 가정:

| 시점 | 이벤트 | 무적 상태 | 적용 데미지 | 남은 HP |
|---|---|---|---|---|
| 0.0초 | 잡몹 탄 피격 | 아님 | 10 | 90 |
| 0.4초 | 잡몹 탄 또 피격 | 무적 중 (1.0초까지) | 0 | 90 |
| 1.5초 | 잡몹 몸체 충돌 | 아님 | 20 | 70 |
| 3.0초 | 보스 탄 피격 | 아님 | 25 | 45 |
