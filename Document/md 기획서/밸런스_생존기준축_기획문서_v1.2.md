| v1.1 | 2026-10-09 | 밸런스 기획 | 2차 개정 (총괄 기획 결정 반영 — 회복 2종, 보스 처치 최대 HP 증가, 스테이지 3개) |

> **v1.2 개정 요약 (총괄 기획 결정 — 아이템시스템 v1.3·v1.4)**
> - **HP 표시**: HP는 **100 단위 그대로**, HUD도 **게이지 + 수치(예: 100/100)**로 표시한다. HUD 시안의 "LIFE 4/4"는 자리표시용 시안일 뿐 칸 단위를 뜻하지 않음 (총괄 기획 확인)
> - **회복 아이템 → 포션**: v1.1의 "체력 회복 아이템(먹는 즉시 회복, 풀 HP면 튕김)"을 **포션**으로 교체. 포션은 슬롯에 최대 3개까지 보관하고 **숫자 1 키**로 사용, HP가 가득 차면 사용 불가. 4개째부터는 점수로 전환 (2.3)
> - `HealItemAmt` → **`PotionHeal`**로 이름 변경, 값은 **20 유지** (2.1)
> - **보스 처치 최대 HP 증가 일원화**: v1.1의 보스 처치 자동 증가(`MaxHPUp`)를 없애고 **보스가 최대 HP 아이템을 확정 드랍**(자동 흡수). 증가량은 v1.1과 같은 **+20**(`MaxHPItemUp`), 현재 HP도 함께 +20 (2.1, 2.2)
> - 최대 HP 성장 단계(100 → 120 → 140)는 v1.1과 같음. 피격 예산(3.3)은 포션 보관을 반영해 재계산
> - 5장 #4(회복 아이템 드랍 조건)의 권장안 변경 — 포션은 보관이 되므로 "풀 HP면 드랍 제외"가 필요 없어짐

> **문서 읽는 법**
> - 본 문서의 모든 수치는 **"정답"이 아니라 "테스트 가능한 가설"**이다. 각 수치에 근거와 조정 범위를 함께 적는다
> - 공식·규칙의 원본은 **데미지시스템 v1.6**, 아이템 분류·포션·최대 HP 아이템 규칙의 원본은 **아이템시스템 v1.4**다. 본 문서는 값을 채우고, 규칙이 새로 필요한 곳은 **[제안]**으로 표시한다
> - **[가정]** — 아직 확정되지 않은 전제를 임시로 둔 것

## 1. 개요

### 1.1 범위
데미지시스템 2.2의 변수 중 **플레이어가 몇 번 맞으면 죽는가**를 결정하는 값, 그리고 **HP 회복·최대 HP 성장** 수치를 정한다.

| 변수 | 의미 | 비고 |
|---|---|---|
| `PlayerMaxHP` | 플레이어 시작 최대 HP | |
| `IFrameTime` | 플레이어 피격 후 무적시간 | |
| `EnemyAtk(skill)` | 적 탄 1발 데미지 (몹 등급별) | |
| `ContactDmg(enemy)` | 적 몸체 충돌 데미지 (몹 등급별) | |
| `AllyIFrameTime` | 얼라 피격 후 무적시간 | |
| `ClearHeal` | 스테이지 클리어 시 자동 회복량 | 확정: 30 |
| `MaxHPItemUp` **(v1.2)** | 최대 HP 아이템 1개의 증가량 (보스 확정 드랍) | v1.1 `MaxHPUp` 대체 |
| `MaxHPCap` **(v1.2)** | 최대 HP 상한 | 신규 |
| `PotionHeal` **(v1.2)** | 포션 1개 회복량 | v1.1 `HealItemAmt` 대체 |
| `PotionMax` **(v1.2)** | 포션 최대 보관 개수 | 아이템 v1.4: 임시 3 |

### 1.2 목표 경험
- **"한 방에 끝나지 않는다"**: 어떤 공격도 단독으로 HP를 크게 깎지 않는다
- **"몇 대 남았는지 감으로 안다"**: 같은 적의 탄은 항상 같은 데미지 (데미지 v1.3 1.2)
- **"아깝게 죽었다"**: 한 발 데미지를 작게 쪼개 "한 대만 덜 맞았으면"이 재도전 동기가 되게 한다
- **"보스를 잡으면 강해진다"**: 보스 처치가 최대 HP라는 눈에 보이는 성장으로 돌아온다
- **(v1.2) "포션을 아껴 둘지, 칸을 비워 줄지"**: 포션은 강화와 슬롯을 나눠 쓰므로, 생존과 화력 사이의 선택이 생긴다

### 1.3 전제
| 항목 | 값 | 상태 / 영향 |
|---|---|---|
| 스테이지 수 | **3스테이지** (각 스테이지 끝 보스 1체) | [가정] 총괄 기획 방향(빠른 출시). 3.3 피격 예산에 반영 |
| 몹 등급 | 잡몹 / 엘리트 / 보스 3등급 | [가정] |
| HP 회복 | 스테이지 클리어 자동 회복 + **포션** | **[확정] v1.2** (아이템 v1.4) |
| 최대 HP 성장 | **보스 처치 시 최대 HP 아이템 확정 드랍** | **[확정] v1.2** (아이템 v1.4) |
| HUD 표시 | **게이지 + 수치 (현재/최대, 예: 100/100)** | **[확정] v1.2** — 시안의 "4/4"는 자리표시 |

## 2. 수치표

### 2.1 플레이어 HP·회복·성장

| 변수 | 초기값 | 테스트 조정 범위 | 근거 |
|---|---|---|---|
| `PlayerMaxHP` (시작값) | **100** | 고정 | 기준 단위. 모든 데미지가 "시작 HP의 몇 %"로 읽힘 |
| `IFrameTime` | **1.2초** | 1.0 ~ 1.5초 | 3.2 참조 |
| `ClearHeal` | **30** | 20 ~ 40 | **[확정]** 총괄 기획 결정. 잡몹 탄 3발분 |
| `MaxHPItemUp` **(v1.2)** | **+20** | +10 ~ +30 | [제안 — v1.1 `MaxHPUp` 값 유지] 잡몹 탄 2발분. 3스테이지 기준 최종 최대 HP 140 (시작 대비 +40%). 그 이상이면 3스테이지가 체감상 너무 쉬워질 위험 (3.4) |
| `MaxHPCap` **(v1.2)** | **140** | 140 ~ 200 | [제안] 현재 구조(보스 2체 처치)에서 도달하는 최대치. 엔드 콘텐츠 스테이지가 붙으면 재검토. 상한 도달 후 최대 HP 아이템은 점수로 전환(아이템 v1.4) |
| `PotionHeal` **(v1.2)** | **20** | 10 ~ 30 | [제안 — v1.1 `HealItemAmt` 값 유지] 잡몹 탄 2발분. `ClearHeal`(30)보다 작게 두어 **스테이지 클리어가 주 회복원**, 포션은 "위급할 때 한 숨 돌리는 수단". 포션이 슬롯을 차지하는 비용이 생겼으므로, 플레이테스트에서 아무도 포션을 안 들고 다니면 25로 상향 (4.1) |
| `PotionMax` | **3** | 2 ~ 3 | [확정] 아이템 v1.4 (임시값). 3개 = 60 → 시작 HP의 60%. 3.3 참조 |

**최대 HP 성장 단계**

| 시점 | 최대 HP | 비고 |
|---|---|---|
| 스테이지 1 시작 | 100 | |
| 보스 1 처치 후 (스테이지 2) | 120 | |
| 보스 2 처치 후 (스테이지 3) | 140 | |
| 보스 3 처치 | — | 마지막 보스 처치 = 전체 클리어 → 엔딩. 추후 엔드 콘텐츠 스테이지가 붙으면 그때 적용 |

### 2.2 보스 처치 시 처리 순서 *(v1.2 개정)*

| 순서 | 처리 | 근거 |
|---|---|---|
| 1 | 보스가 최대 HP 아이템 1개를 확정 드랍 → **즉시 자동 흡수** | [제안 — 아이템 v1.4 2.3 ⑤] 보스 처치 직후 스테이지 전환이 일어나므로 필드에 두면 놓칠 수 있음 |
| 2 | 최대 HP `+20`, **현재 HP도 `+20`** | [확정] 아이템 v1.4 "늘어난 만큼 채워진 상태로" |
| 3 | 현재 HP `+ClearHeal(30)` (최대 HP 초과 불가) | 늘어난 최대 HP 기준으로 회복 → 성장 직후 회복이 낭비 없이 들어감 |

- 예시: 스테이지 1을 HP 40으로 클리어 → 최대 120, 현재 60 → +30 → **90/120**으로 스테이지 2 시작
- 예시: 무피격(HP 100)으로 클리어 → 최대 120, 현재 120 → +30은 초과분 버려짐 → **120/120**

### 2.3 포션 규칙 *(v1.2 — v1.1 "체력 회복 아이템" 대체)*

규칙의 원본은 아이템 v1.4 2.6 ②. 본 절은 밸런스 관점의 값과 근거만 정리한다.

| 항목 | 규칙 | 근거 |
|---|---|---|
| 분류 | ② 사용 아이템 (①·② 공용 슬롯 3칸 중 1칸 차지) | [확정] 아이템 v1.4 |
| 획득 경로 | 적 처치 드랍 | [확정] |
| 사용 | **숫자 1 키**, 1개 소모, `PotionHeal` = 20 회복 (최대 HP 초과 불가) | [확정] 키 / [제안] 회복량 |
| HP가 가득 찼을 때 사용 | **사용 불가** (소모 안 됨) | [확정] 아이템 v1.4 |
| 4개째 획득 | 흡수 후 점수(`OverflowBonus`)로 전환 | [확정] 아이템 v1.3 |
| HP가 조금만 비었을 때 사용 (예: 115/120) | 사용됨, 넘치는 양은 버림 | [제안] — "가득 찼을 때만 막는다"는 확정 규칙 그대로. 낭비 여부는 플레이어 판단 |
| 드랍 빈도 | **3순위(아이템 수급축) 문서에서 결정.** 목표: **스테이지당 기대 획득 0.5~1개** (v1.1의 1~2개에서 하향) | 3.3 — 포션은 보관이 가능해 낭비 없이 전부 쓰이므로, 같은 개수라도 v1.1 회복 아이템보다 실질 회복량이 큼 |

### 2.4 적 탄 데미지 (`EnemyAtk`)

| 등급 | 탄 1발 | 시작 HP(100) 대비 | 풀 HP에서 사망까지 (스테이지 1) | 근거 |
|---|---|---|---|---|
| 잡몹 | **10** | 10% | 10발 | **기준 지표** (`PlayerMaxHP ÷ EnemyAtk`) |
| 엘리트 | **15** | 15% | 7발 | 잡몹의 1.5배. 위계를 체감할 수 있는 최소 차이 |
| 보스 일반탄 | **20** | 20% | 5발 | 잡몹의 2배 |
| 보스 필살 패턴 | **25** | 25% | 4발 | **단일 피격 상한** |

> 스테이지별 데미지 변화 여부는 미결 → 5장 #3. 위 표는 옵션 ⓐ(고정) 기준 값이다.

### 2.5 몸체 충돌 데미지 (`ContactDmg`)

| 등급 | 충돌 데미지 | 같은 등급 탄 대비 | 근거 |
|---|---|---|---|
| 잡몹 | **15** | 1.5배 | 충돌은 보이고 피하기 쉬움 → 탄보다 아프게 해서 몸으로 밀고 들어가기 억제 |
| 엘리트 | **20** | 1.33배 | 상한 이내 |
| 보스 | **25** | 상한 | 보스 몸체는 크고 오래 머물러 충돌이 잦으므로 상한 이상은 주지 않음 |

> **단일 피격 상한 = 25**: 탄·충돌 통틀어 25를 넘지 않는다. 동시 다중 피격은 "가장 큰 값 1회만"(데미지 v1.3)이므로 한 순간 최대 손실도 25.

## 3. 곡선 및 상세 근거

### 3.1 데미지 위계 (텍스트 그래프)

```
데미지
25 |                              ■ 보스 필살  ■ 보스 충돌   ← 단일 피격 상한
20 |                    ■ 보스 일반탄  ■ 엘리트 충돌
15 |          ■ 엘리트 탄  ■ 잡몹 충돌
10 |  ■ 잡몹 탄
   +---------------------------------------------------
      잡몹 탄 기준 1.0배 → 1.5배 → 2.0배 → 2.5배 (상한)
```

### 3.2 `IFrameTime` 1.2초의 근거

| 검토 관점 | 계산 / 판단 |
|---|---|
| 최소 사망 시간 (스테이지 1, 풀 HP, 쉬지 않고 맞을 때) | 잡몹 탄: 9회 × 1.2초 = **10.8초** / 보스 필살: 3회 × 1.2초 = **3.6초** → 한 패턴 실수로 즉사 없음 |
| 탄막 탈출 시간 | 이동 속도 확정 후 "1.2초 동안 기체 폭의 몇 배를 움직이는가"로 재검증 (5장) |
| 무적 악용 | 탄이 통과하므로 무적 중 탄막 가로지르기가 가능. 관찰되면 1.0초로 하향 |
| 갈고리 조준 중 (이동 불가, 피격 가능) | 잡몹 탄막 속 5초 지연 시 약 4회(40) 손실 → 아프지만 즉사 수준은 아님. **(v1.2) 조준 중에도 포션 사용 가능(아이템 v1.4 [제안])이라 위급 시 20 회복 여지** |

### 3.3 런 전체 피격 예산 *(v1.2 재계산)*

"한 판 동안 얼마나 맞아도 되는가"를 잡몹 탄(10) 환산으로 계산. 회복이 최대 HP를 넘어 버려지는 손실은 없다고 가정한 **최대치**.

| 구성 | 런 전체 HP 풀 | 잡몹 탄 환산 | 스테이지당 평균 |
|---|---|---|---|
| 시작 HP | 100 | | |
| + 보스 1·2 처치 최대 HP 아이템 (20 × 2) | +40 | | |
| + 클리어 회복 (`ClearHeal` 30 × 2) | +60 | | |
| **소계 (포션 제외)** | **200** | **20발** | **약 6.7발** |
| + 포션 (스테이지당 0.5개 × 3 = 1.5개 × 20) | +30 | | |
| **합계 (포션 스테이지당 0.5개)** | **230** | **23발** | **약 7.7발** |
| 합계 (포션 스테이지당 1개) | 260 | 26발 | 약 8.7발 |

> - 보스 3 처치는 엔딩이므로 성장·회복을 계산에 넣지 않음
> - **목표 예산: 스테이지당 7~9발**. v1.1(6~8발)보다 위쪽을 조금 열어 둔 이유: 포션이 보관 가능해져 "필요할 때 정확히 쓰이는" 회복이 되었고, 슬롯 비용으로 화력을 일부 포기하는 대가가 붙었기 때문
> - 포션 기대 획득이 스테이지당 1개를 넘으면 예산이 9발을 넘어 긴장감이 떨어짐 → 3순위 문서에서 포션 `DropChance`를 이 상한에 맞춤
> - **포션 보관의 영향**: 포션은 쓰지 않고 다음 스테이지로 가져갈 수 있다. 스테이지 1·2에서 아껴 3개를 모은 뒤 스테이지 3(가장 어려운 구간)에서 한꺼번에 쓰는 플레이가 가능 → 스테이지 3에서 순간적으로 **+60** 여유가 생김. 의도된 전략으로 보되, 4.1 지표로 감시
> - **포션의 슬롯 비용**: 포션을 들고 있으면 강화 1칸을 못 쓰므로, 생존 여유와 화력이 맞바뀐다. 3순위 문서에서 "포션 보유 시 화력 손실"을 함께 검토

### 3.4 최대 HP 성장이 데미지 체감에 미치는 영향

탄 데미지를 고정(옵션 ⓐ)하면, 최대 HP가 커지는 만큼 **같은 탄의 상대적 위력이 줄어든다.**

| 스테이지 | 최대 HP | 잡몹 탄 10 비중 | 잡몹 탄 사망까지 | 보스 필살 25 비중 | 보스 필살 사망까지 |
|---|---|---|---|---|---|
| 1 | 100 | 10% | 10발 | 25% | 4발 |
| 2 | 120 | 8.3% | 12발 | 20.8% | 5발 |
| 3 | 140 | 7.1% | 14발 | 17.9% | 6발 |

- 이것이 **"보스를 잡으면 강해진다"는 보상의 실체**다
- 3스테이지 난이도를 올리려면 **탄 밀도·속도를 더 크게** 올려야 함. **(v1.2) 포션 비축(3.3)까지 더해져 스테이지 3 보강 필요성이 v1.1보다 커짐** → 5장 #3

## 4. 검증 계획

### 4.1 핵심 지표와 목표치 (가설)

| 지표 | 목표 (첫 플레이 기준) | 벗어날 때 조정 방향 |
|---|---|---|
| 스테이지 1 클리어율 | 80% 이상 | 미달 → 1스테이지 탄 밀도 하향 요청 |
| 보스전 사망 중 "보스 HP 30% 이하 남기고 사망" 비율 | 40% 이상 | 미달 → 보스 필살 25 → 20 또는 보스 직전 회복 구간 |
| 피격 1회당 평균 HP 손실 | 11~13 | 15 이상 → 엘리트·충돌 비중 검토 |
| 무적 중 탄막 관통 이동 | 관찰되지 않음 | 반복 관찰 → `IFrameTime` 1.0초 |
| 갈고리 조준 1회당 피격 | 평균 0.5회 이하 | 초과 → 슬로우모션 해제 시간 조정 |
| 얼라 소멸 원인 (HP 0 vs 교체) | 교체가 대다수면 무적 과다 | `AllyIFrameTime` 제거 (데미지 v1.1 재검토 조건) |
| 스테이지별 진입 시 HP 비율 | 스테이지 2·3 진입 평균 **60~80%** | 90% 이상 → 회복 과다 (`ClearHeal`·`PotionHeal` 하향) / 50% 미만 → 회복 부족 |
| **(v1.2) 포션 사용 시점의 HP** | 평균 **최대 HP의 50% 이하**에서 사용 | 70% 이상에서 자주 사용 → 포션이 흔해서 아끼지 않음 = 드랍 과다 |
| **(v1.2) 스테이지 3 진입 시 보유 포션 수** | 평균 **1개 이하** | 2개 이상 → 포션 비축 플레이가 지배적 = 스테이지 3이 쉬워짐. 드랍 하향 또는 `PotionMax` 2로 |
| **(v1.2) 포션 초과 획득(점수 전환) 비율** | 포션 획득 중 20% 이하 | 초과 → 드랍 과다 |
| **(v1.2) 포션 보유 중 슬롯 구성** | 포션 + 강화 2종이 흔한지 관찰 | 포션을 아예 안 들고 다니면 → `PotionHeal` 25로 상향 / 항상 들고 다니면 → 화력 손실이 작음 |
| 스테이지 3 사망률 vs 스테이지 2 사망률 | 스테이지 3이 더 높음 | 역전 → 최대 HP 성장·포션 비축으로 3스테이지가 쉬워짐. 5장 #3 옵션 재검토 |

### 4.2 테스트 방법
- 피격 로그(시각, 원인 등급, 탄/충돌, 남은 HP, 조준 중 여부), 사망 로그(스테이지, 보스 남은 HP %), 회복 로그(원천: 클리어/**포션**, 회복량, 버려진 초과분), **(v1.2) 포션 로그**(획득·사용 시점, 사용 시 HP, 보유 개수, 사용 불가 입력 횟수)를 수집
- 조정은 한 번에 하나의 변수만. 우선순위: 레벨 밀도 → `IFrameTime` → 회복량 → `EnemyAtk`
- 지표·로그 항목은 QA/테스트 기획과 사전 공유
