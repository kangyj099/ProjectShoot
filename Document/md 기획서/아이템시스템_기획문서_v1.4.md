> **v1.4 개정 요약 (총괄 기획 결정)**
> - **HP 표시 (R)**: HP는 **100 단위**(밸런스 생존기준축 기준) 그대로, HUD도 **게이지 + 수치(예: 100/100)**로 표시. HUD 시안의 "LIFE 4/4"는 자리표시일 뿐 칸 단위가 아님 (총괄 기획 확인)
> - **최대 HP 성장 경로 일원화 (S)**: 보스 처치 시 최대 HP 자동 증가를 없애고, **보스가 최대 HP 아이템을 확정 드랍**. 최대 HP 아이템 1개 = 최대 HP **+20**(`MaxHPItemUp`, 밸런스 v1.1 값 유지)
> - **포션 (K)**: 사용 키는 **숫자 1** 전용 키, **HP가 가득 찼을 때는 사용 불가**(포션이 소모되지 않음)
> - **회복 아이템 정리**: 밸런스 생존기준축 v1.1의 "먹는 즉시 회복, 풀 HP면 튕김" 회복 아이템을 **포션으로 대체** (밸런스 v1.2에서 반영)
> - **HUD 슬롯 (P)**: 시안의 ITEM 아래 **작은 칸 3개가 ①·② 공용 슬롯**(`SlotMax = 3`)이다. 그 아래 큰 칸의 용도는 아이템 슬롯이 아니며 별도 확인 (UI)
> - 연동 문서: **밸런스 생존기준축 v1.2**, **조작 v1.2**(포션 키 추가), **데미지 v1.6**(HP 단위 표기)

> **v1.3 개정 요약 (총괄 기획 결정)**
> - **아이템을 "슬롯 사용 여부 × 조작 필요 여부"로 4분류** (2.1)
>
>   | 분류 | 슬롯 | 조작 | 해당 아이템 |
>   |---|---|---|---|
>   | ① 강화 아이템 | 들어감 | 필요 없음 | 공격력 증가, 탄 개수 증가, 탄 크기 증가 |
>   | ② 사용 아이템 | 들어감 | 단축키로 사용 | 포션 |
>   | ③ 즉시 아이템 | 안 들어감 | 필요 없음 | 무기 교체, 최대 HP 증가 |
>   | ④ 버프 아이템 | 안 들어감 (HUD 우측 버프 영역) | 필요 없음 | 일시 공격 배수 |
>
> - v1.2의 "체력 증가(사용형 강화)"는 **포션(② 사용 아이템)**과 **최대 HP 증가(③ 즉시 아이템)** 두 개로 분리
> - **포션**: 최대 3개까지 개수로 쌓임, 단축키로 1개씩 사용(HP 회복), 0개가 되면 슬롯이 빔
> - **최대 HP 증가**: 최대 HP가 늘고, 늘어난 만큼 현재 HP도 함께 채워짐 *(v1.4 정정: 칸이 아닌 게이지 기준 — 증가량 +20)*
> - **효과 없는 획득 처리 변경**: 튕겨나가는 아이템이 많으면 시야가 어지러워지므로
>   - **무기 교체만 튕겨나감** (기존 유지)
>   - **나머지(강화 Lv3·포션 3개 가득·최대 HP 상한·약한 배수)는 흡수되고 점수로 전환** → 스코어 시스템에 새 점수 원천 추가 (스코어 v1.4)
> - **흐림 표시는 무기 아이템에만** 적용 (튕겨나가는 아이템이 무기뿐이므로)
> - **탄 크기 증가는 일단 유지.** 강화 종류 구성은 밸런스 기획과 함께 재검토 예정
> - 연동 문서 동시 개정: **총알스킬 v1.4**(용어 표), **데미지 v1.5**(최대 HP 가변, 포션 회복, 약한 배수 점수 전환), **스코어 v1.4**(초과 획득 점수 신설)
> - **밸런스 생존기준축 v1.1과의 관계**: 그 문서의 "체력 회복 아이템(먹는 즉시 회복, 풀 HP면 튕김)"은 이번 결정으로 **포션(슬롯 보관 + 단축키 사용)으로 대체**된다. 또한 그 문서는 HP를 100 단위로, 이번 HUD 시안은 칸 단위(LIFE 4/4)로 표기하고 있고, 보스 처치 시 자동 최대 HP 증가(`MaxHPUp`)와 이번 최대 HP 아이템의 관계도 정해지지 않았다 → 5장 R·S

## 1. 개요

### 1.1 목적
본 문서는 모든 아이템의 분류·생애주기·효과 규칙을 한곳에 모은 **아이템 관련 단일 참조 문서**이며, 슬롯(강화·사용 아이템)의 원본 문서다.

### 1.2 플레이어 경험 목표
- **한눈에 구분**: 화면의 아이템이 무엇인지, 먹을 수 있는지 0.1초 안에 알아볼 수 있다
- **"잡으면 나온다"**: 아이템은 적 처치로만 생긴다 (슬롯 배출 제외)
- **빌드를 고르는 재미**: 슬롯은 3칸뿐이라 무엇을 키우고 무엇을 버릴지 매 판 다르게 고르게 된다. **포션도 같은 슬롯을 쓰므로 "공격을 키울지, 회복을 쌓아둘지"가 갈린다 (v1.3)**
- **실수해도 되돌릴 수 있음**: 밀려난 슬롯 아이템은 레벨·개수를 유지한 채 필드에 떨어진다
- **먹어서 손해 보는 일 없음 (v1.3)**: 효과가 없는 아이템도 점수로 바뀌므로 "먹으면 항상 뭔가 생긴다". 튕겨나가는 것은 무기뿐이라 화면이 어지럽지 않다

## 2. 상세 규칙

### 2.1 아이템 분류 *(v1.3 개편)* [확정]

| 분류 | 슬롯 | 조작 | 해당 아이템 | 효과 없는 획득 |
|---|---|---|---|---|
| **① 강화 아이템** | 강화·사용 공용 슬롯 | 없음 (보유하는 동안 자동 적용) | 공격력 증가, 탄 개수 증가, 탄 크기 증가 | 같은 종류 Lv3 → **점수** |
| **② 사용 아이템** | 강화·사용 공용 슬롯 | **단축키로 사용** | 포션 | 3개 가득 → **점수** |
| **③ 즉시 아이템** | 없음 | 없음 (먹는 즉시 적용) | 무기 교체, 최대 HP 증가 | 같은 무기 → **튕김** / 최대 HP 상한 → **점수** |
| **④ 버프 아이템** | 없음 (HUD 우측 **버프 영역**에 표시) | 없음 (먹는 즉시, 정해진 시간 동안) | 일시 공격 배수 | 약한 배수 → **점수** |

- **적용 대상**: 모든 아이템은 **플레이어 전용** [확정](데미지 v1.3)
- **용어 메모**: 총알스킬 v1.2에서 "버프 아이템"을 사용 금지 용어로 정했으나, v1.3에서 **"버프 아이템"을 ④ 분류의 이름으로 다시 사용**한다. 개별 아이템명은 계속 "일시 공격 배수 아이템"으로 쓰고, "버프 아이템"은 "시간제로 적용되고 버프 영역에 표시되는 아이템 묶음"만 가리킨다. 앞으로 시간제 효과(이동 속도 증가 등)가 늘어나면 ④에 들어간다 [제안]
- **"파워업"은 계속 사용하지 않는다**

### 2.2 아이템 생애주기

```
적 처치 ─────→ 드랍 ─┐
슬롯 아이템 배출 ────┴→ 필드 체류 ─┬→ 플레이어 접촉 ─┬→ 효과 있음 ─────→ 획득 → 효과 적용
                                  │                 ├→ 효과 없음(무기) → 튕겨나감 → 필드 체류로 복귀
                                  │                 └→ 효과 없음(그 외) → 흡수 → 점수 지급
                                  └→ 화면 이탈 / 체류 종료 → 소멸
```

| 단계 | 정의 위치 |
|---|---|
| 생성 (드랍·배출) | 2.3 |
| 필드 체류 (흐림 표시 포함) | 2.4 |
| 획득 | 2.5 |
| 효과 적용 (분류별) | 2.6 |
| 효과 없는 획득 (튕김 / 점수 전환) | 2.7 |
| 초기화·유지 | 2.8 |

### 2.7 효과 없는 획득 처리 *(v1.3 개편)*

#### 2.7-1 튕겨나감 — 무기 아이템만 [확정]

| 경우 | 처리 |
|---|---|
| 현재 장착 중인 것과 같은 무기 | 획득되지 않고 기체에 튕겨나감. 필드에 남음. 흐리게 표시 |

튕김 세부 규칙 (v1.1·v1.2와 동일): 기체 → 아이템 방향으로 밀려난 뒤 원래 이동 복귀 / 재접촉 시 그 순간 상태로 재판단 / 튕긴 직후 `BounceIgnoreTime` 동안 접촉 무시 / 플레이어에게 데미지·밀림·무적 없음 [제안]

#### 2.7-2 점수 전환 — 그 외 전부 [확정]

| 경우 | 분류 |
|---|---|
| 같은 종류 강화가 Lv3일 때 그 강화 획득 | ① 강화 |
| 포션 3개 보유 중 포션 획득 | ② 사용 |
| 최대 HP가 `MaxHPCap`일 때 최대 HP 아이템 획득 | ③ 즉시 |
| 강한 배수 적용 중 약한 배수 획득 | ④ 버프 |

| 항목 | 규칙 | 상태 |
|---|---|---|
| 처리 | 아이템은 **흡수되어 사라지고**, 효과 대신 **초과 획득 점수 `OverflowBonus`** 지급 | [확정] 점수 전환 / [제안] 변수명 |
| 점수 값 | 4가지 경우 모두 같은 값 | [제안] — 경우별 차등은 5장 Q |
| 피드백 | 획득 연출 대신 점수 팝업 | [제안] — UI 협의 |
| 점수 원본 | 스코어 v1.4 2.1·2.5 | — |

> **설계 의도 (총괄 기획 결정)**: 튕겨나가는 아이템이 많아지면 탄막 속에서 시야가 어지러워진다. 무기를 제외한 상한 아이템은 흡수해서 화면에서 바로 치우고, 그 보상으로 점수를 준다. 무기만 튕기는 이유는, 같은 무기는 드랍 단계에서 대부분 걸러져 튕김이 드물게 일어나고, 다른 무기로 바꾼 뒤 다시 먹을 가치가 있기 때문이다.
