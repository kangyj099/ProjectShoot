## 1. 개요

### 1.1 목적
조작 시스템은 코어 루프(이동-회피-사격-포획)를 플레이어가 실제 손으로 구현하는 인터페이스다. 본 게임은 **WASD와 방향키(화살표 키)를 동일한 이동 입력으로 병행 지원**하여 양손을 모두 사용하는 조작을 기본으로 하고, **사격은 완전 자동화**하여 플레이어가 "어떻게 맞힐까"가 아니라 "어디로 움직일까"에만 집중하도록 만든다. 이는 코어 루프 문서의 캐주얼 접근성 목표와 직결된다.

### 1.2 플레이어 경험 목표
- **양손 조작의 안정감**: WASD(왼손)와 방향키(오른손)를 동시에 지원해, 한 손만으로 조작하는 구조 대비 더 넓고 안정적인 입력 자세를 제공
- **판단에 집중하는 조작**: 사격을 자동화해 플레이어의 의식적 조작 리소스를 이동(회피)과 갈고리 판단(포획 여부)에 집중시킴
- **즉각적 반응**: 입력 즉시 캐릭터가 반응하는 것을 기본 방향으로 하여, 캐주얼 슈팅 특유의 "맞았다/피했다"가 명확히 체감되도록 함
- **단순함 유지**: 별도 회피기를 두지 않고 이동만으로 회피가 성립하도록 하며, **입력 키는 이동 + 갈고리 + 포션 3종류로 최소화** (v1.2)

## 2. 상세 규칙

### 2.1 이동 방식 *(v1.1 개정 — 마우스 제외, 양손 조작으로 전환)*

| 항목 | 규칙 |
|---|---|
| 입력 수단 | **키보드만 사용** — WASD, 방향키(화살표 키) **동시 지원** |
| 입력 우선순위 | 별도 우선순위 없음 — WASD와 방향키 모두 동일한 "이동" 명령으로 취급, 플레이어가 편한 방식을 자유롭게 선택/혼용 (양손 동시 사용도 가능) |
| 마우스 사용 여부 | **이동에 사용하지 않음** (v1.0의 마우스 추종 방식 폐기) |
| 이동 범위 | 화면(플레이 필드) 내 자유 이동 — 8방향(대각선 포함) 이동 지원 |
| 반응성 기준(제안) | 입력 즉시 반응, 관성/가속 없는 즉각 이동을 기본 방향으로 제안 (캐주얼 장르의 명확한 피드백 우선) |

> **설계 의도(v1.1)**: WASD와 방향키를 동시에 지원하는 것은 **양손을 각각의 키 그룹에 배치해 안정적으로 이동에 집중**할 수 있게 하기 위함이다.

### 2.2 사격 방식

| 항목 | 규칙 |
|---|---|
| 발사 트리거 | **자동 사격** — 별도 사격 버튼 없이 상시 발사 |
| 조준(발사) 방향 | **항상 상단(전방) 고정 방향**으로 발사 (조준 입력 자체가 없음) |
| 발사 중인 무기 | 현재 장착된 스킬(무기)에 따름 — 총알스킬시스템 문서 참조 |

### 2.3 회피 시스템 *(v1.1 확정 — 별도 회피기 개발 안 함)*

- 대시/무적시간 등 **별도의 회피 전용 기능은 개발하지 않는 것으로 확정**되었다.
- 탄막 회피는 **2.1의 이동(WASD+방향키)만으로 성립**하는 것을 기본 방향으로 한다.
- 이는 회피용 키를 따로 두지 않고, 개발 리소스를 이동/사격/갈고리 등 핵심 시스템에 집중하기 위한 결정이다. *(v1.2: "추가 키 바인딩 불필요"는 회피기에 대한 설명이며, 사용 아이템 키는 2.5에서 별도로 추가됨)*

> **레벨/밸런스 영향**: 회피 수단이 순수 이동뿐이므로, 탄막 밀도·몹 배치·이동 속도를 설계할 때 "이동만으로 충분히 회피 가능한 난이도"를 전제로 조정해야 한다.

### 2.4 갈고리 스킬 조작 연계

갈고리 시스템의 "스킬키 2회 입력(1차: 조준 가이드라인 생성+시간정지 발동 → 2차: 실제 발사)" 구조를 그대로 따른다. **스킬키는 스페이스바** (v1.2 확정).

| 구간 | 이동(WASD/방향키) | 사격(자동) | 포션(숫자 1) *(v1.2)* |
|---|---|---|---|
| 갈고리 미사용 시(평상시) | 가능 | 자동 발사 지속 | 사용 가능 |
| 1차 입력 직후 ~ 2차 입력(실제 발사) 전까지 | **불가** — 조준 가이드라인이 좌우로 왕복하는 동안 캐릭터는 정지 상태 유지 | **가능** | **사용 가능** [제안 — 아이템 v1.4] |
| 2차 입력(실제 발사) 이후 | 즉시 재개 | 계속 가능 | 사용 가능 |

- 갈고리 조준 구간 동안 **WASD/방향키를 입력해도 캐릭터 위치는 반응하지 않는다**.
- 이 구간에도 자동 사격은 유지된다.
- 회피기가 없는 구조이므로, 갈고리 조준 중 이동 불가 상태는 곧 "이 구간 동안은 순수 위치 고정 상태"를 의미한다. 시간정지가 풀린 뒤에는 피격될 수 있으므로(갈고리 v1.4), **(v1.2) 이 구간에서 포션은 위급 시 쓸 수 있는 유일한 대응 수단**이 된다.

### 2.5 입력 키 목록 *(v1.2 신설)*

| 동작 | 키 | 입력 방식 | 상태 | 정의 문서 |
|---|---|---|---|---|
| 이동 | WASD / 방향키 (동시 지원) | 누르는 동안 이동 | [확정] | 본 문서 2.1 |
| 사격 | 없음 (자동) | — | [확정] | 본 문서 2.2 |
| 갈고리 | **스페이스바** | 1회: 조준 시작 / 2회: 발사 | **[확정] v1.2** | 갈고리 v1.5 |
| **포션 사용** | **숫자 1** | 1회 누를 때마다 포션 1개 사용 | **[확정] v1.2** | 아이템 v1.4 2.6 ② |

**포션 키 규칙**

| 상황 | 처리 | 상태 |
|---|---|---|
| 포션 보유 + HP가 가득 차지 않음 | 포션 1개 소모, `PotionHeal`만큼 회복 | [확정] |
| HP가 가득 참 | **사용 불가** — 소모되지 않고 짧은 "사용 불가" 피드백 | [확정] |
| 포션 없음 | 아무 일도 없음, 짧은 피드백 | [제안] |
| 키를 누르고 있기 | **1회만 사용** (꾹 누른다고 연속 사용되지 않음) | [제안] — 위급할 때 연타·꾹 누르기로 포션을 한꺼번에 날리는 실수 방지 |
| 사용 직후 재사용 간격 | 없음 (연속으로 누르면 연속 사용) | [제안] — 쿨타임을 두면 조작이 복잡해짐. 남용은 슬롯·보관 개수(3)로 제한됨 |
| 무적시간 중 / 갈고리 조준 중 | 사용 가능 | [제안] |

> **키 위치 메모**: 숫자 1은 W 바로 위에 있어, **방향키로 이동하는 플레이어(왼손이 비어 있음)**는 부담 없이 누를 수 있다. **WASD로 이동하는 플레이어**는 이동 중인 왼손을 잠깐 떼야 하므로, 위급한 순간 이동이 멈출 수 있다. 플레이테스트에서 확인하고, 필요하면 키 재배치 옵션(5장)으로 보완한다.
